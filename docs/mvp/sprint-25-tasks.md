## 2. Решения (утверждены 2026-11-05)

1. **Отдельные списки + связь «задача → список».** У задачи можно выбрать один список; на задаче — «🛒 Groceries · 3/8 ›», пункты отмечаются прямо оттуда. Отдельного чеклиста внутри задачи нет — это тот же список.
2. **Навигация.** Телефон: Home · Calendar · [+] · **Lists** · Profile. Progress — карточкой на Home («Эта неделя · 80% →») и ссылкой в Profile; сам экран не меняется. Компьютер: Lists в боковом меню после Tasks. «+ New list» — на экране Lists; общий «+» остаётся для задач.
3. **Закреплённый список** — строкой на Home («🛒 Groceries · 3/8 ›»).
4. **Экран списка.** Пункт добавляется одной строкой, Enter — сразу следующий. Отметить, удалить, переставить. Отмеченные — вниз, зачёркнутые. Кнопки «Uncheck all» (тренировка, сборы) и «Clear checked» (покупки).
5. **Заметка у пункта** — необязательная («молоко — 2 л», «присед — 3×12»).
6. **Шаблоны** (все): 🛒 Покупки · 🧳 Сборы в дорогу · 🏋️ Тренировка · 💊 Аптечка / лекарства · 🏠 Уборка · 🎁 Подарки · 📚 Хочу прочитать / посмотреть · 📝 К врачу / на встречу · пустой. Шаблон задаёт название, значок и несколько стартовых пунктов, их можно удалить. Список людей (гости, кому позвонить) — обычный список.
7. **Telegram:** `/lists` (и кнопка на клавиатуре бота); список — пункты кнопками, нажатие отмечает и перерисовывает сообщение; добавление пунктов текстом; в напоминании о задаче со списком — кнопка «Groceries · 3/8».
8. **Не входит:** общий доступ к списку (нужны другие пользователи), записная книжка людей (бэклог п.13), повтор списка по расписанию.

## 3. Вопросы Q1–Q4 — взяты рекомендации (2026-11-05, «делай спринт 25»; можно поменять до S25-02 / S25-05 / S25-06)

- **Q1. Пункты текстом в боте** — кнопка «+ Add items» под списком → бот: «Send items for Groceries — one per line or separated by commas» (`force_reply`); ответ на это сообщение уходит в список. Текст без reply — по-прежнему задача.
- **Q2. Перестановка** — перетаскивание пальцем, своя реализация на pointer events, без новой библиотеки.
- **Q3. Новые пункты** — в конец списка.
- **Q4. Повторяющаяся задача со списком** — отметки снимаются вручную («Uncheck all»); автосброс — потом, если понадобится.
