### Решения (к утверждению в S20-00)

**Конец серии**

1. **Где хранить.** В JSON правила: `until: "YYYY-MM-DD"` (последний день включительно). Миграции не нужно, старые правила без `until` — бесконечные. «10 раз» превращается в `until` при создании (дата 10-го повторения). Рекомендация: так.
2. **Генерация.** Создание, продление cron и замена при правке не выходят за `until`. После последнего дня серия просто заканчивается: в Tasks — «↻ Daily until Nov 2», после — как законченная (`endedAt` из Sprint 19 ставится cron'ом на следующий день после `until`). Рекомендация: так.
3. **Форма.** Под Repeat — «Ends: Never · On date · After N times». Разбор фраз: «for a month / for 2 weeks / for 10 days», «until Nov 3», «на месяц / на 2 недели / до 3 ноября», «на місяць / до 3 листопада»; «в течение месяца».

**Каждые N дней**

4. **«Через день», «every other day», «every 3 days».** В JSON `DAILY` — `interval: N` (по умолчанию 1); дни считаются от даты начала серии (якоря), как сейчас считается MONTHLY. Форма: Repeat → «Every N days» с числом. Рекомендация: так; «каждые N недель» — §2.

**Несколько приёмов в день**

5. **Как хранить «2 раза в день».** (а) Одна задача с несколькими временами — ломает правило «одно повторение серии в день» (план замены, исключения Sprint 19, `keptDates` по дате). (б) Отдельная задача на каждый приём, как уже делает разбиение фразы: «Таблетки — утро» и «Таблетки — вечер», каждая со своей серией и концом. Рекомендация: (б) — без изменения модели; форма показывает «Will be added as 2 tasks».
6. **«Утром» и «вечером» без часов.** Варианты: (а) время по умолчанию — 09:00 и 20:00, Flexible, напоминание «At start time»; (б) задачи без времени с напоминанием «That morning 09:00» и новым «That evening, 19:00». Рекомендация: (а) — у приёма лекарства должно быть время, его легко поправить; «2 раза в день» без слов — тоже 09:00 и 20:00.

**Срок «до 12:00»**

7. **Модель.** У задачи без времени — `Task.dueMinutes Int?` (минуты дня, «до 12:00» = 720). Это не время начала: в Calendar и на Home задача остаётся в «Any time», с подписью «by 12:00». Миграция — одно nullable поле (только добавление). Рекомендация: так.
8. **Напоминание.** Новый вид `BEFORE_DUE` (минуты до срока: 30 по умолчанию, список как у «за N минут»); уходит, только если задача ещё не отмечена — уже так: Done/Skip отменяют напоминание. Добавление значения в enum — тоже только добавление.
9. **Просрочена** — после срока, а не после конца дня («Overdue since 12:00»). На Home такая задача поднимается в Up next ближе к сроку? — решить в S20-00; рекомендация: Up next — как у задач без времени, но с «by 12:00».
10. **Разбор фраз:** «до 12», «до 12:00», «by noon», «by 12», «до обеда»?, «до 12-ї».

**Даты цифрами**

11. **`03/10` = 3 октября** — всегда день/месяц (интерфейс английский, но пользователи — в Европе); также `3/10`, `03.10`, `03/10/2026`, `03.10.26`. Без года — то же правило, что у «October 3»: этот год, или следующий, если уже прошёл. Время рядом («03/10 at 9») — как сейчас. Рекомендация: так; переключатель ДД/ММ ↔ ММ/ДД в настройках — §2.

**Миграция**

12. Одна, только добавления: `Task.dueMinutes Int?`, значение `BEFORE_DUE` в `ReminderKind`. Превью PR применяет её к проду — PR, когда миграция окончательная.
